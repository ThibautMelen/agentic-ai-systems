# Contributing 🐔

Thanks for helping the coop!

## Requirements (every PR)

- **Official sources** — claims link to primary docs (dated when the fact is time-sensitive)
- **Code examples** — runnable beats pseudocode; if it's a `.nika.yaml`, it must pass `nika check`
- **Mermaid diagrams** — follow [Visual Standards](reference/visual-standards.md)
- **Established format** — breadcrumb header, TL;DR quote, bottom nav (copy an existing page)

## Flow

1. Open an issue first for new patterns ([pattern proposal template](.github/ISSUE_TEMPLATE/pattern-proposal.md))
2. One pattern/topic per PR
3. Run a link check before pushing (every relative link must resolve to a real file)

## What gets rejected

- Content without sources · dead links · diagrams off-standard
- Vendor pitches without disclosure (disclosed first-party examples are fine — this repo has one: [Patterns as Code](patterns-as-code/))
